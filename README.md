## 📌 О проекте

**AutoLead AI** — это сквозное AI-решение для автоматизации квалификации входящих B2B-лидов в режиме реального времени. Система анализирует неструктурированный текст обращения на естественном языке, обогащает данные компании через внешние реестры контрагентов (ФНС / СПАРК), рассчитывает многофакторный балл качества лида (*Lead Score*), регистрирует сделку в CRM (Битрикс24 / amoCRM) и мгновенно эскалирует VIP-заявки руководству компании.

### Ключевые метрики эффективности:
- **Сокращение себестоимости разбора 1 лида:** с **86.48 руб.** (ручной труд SDR) до **0.114 руб.** (в 758 раз).
- **Время первого контакта с клиентом:** сокращено с 40 минут до **$\le 15$ секунд** в режиме 24/7.
- **Точка окупаемости (BEP):** $7\,526$ обработанных обращений (**7.5 календарных дней** при потоке 1 000 лидов/день).
- **Чистый годовой экономический эффект:** **29.24 млн руб.** при **ROI 4 499%**.

### 1. Клонирование репозитория и окружение

## 🧠 Архитектура AI-агента

Прототип агента собран на базе контроллера `create_agent` с чекпоинтером сессий `InMemorySaver`:
- **`enrich_company_data`** *(чтение)*: извлекает выручку, численность штата, кредитный рейтинг и профиль компании.
- **`crm_register_lead`** *(запись / мутация)*: формирует карточку сделки в CRM с назначенным менеджером.
- **`escalate_vip_opportunity`** *(действие)*: экстренный алерт руководству продаж в Slack/Telegram по сделкам с бюджетом $> 1$ млн руб.
- **Human-in-the-Loop (HITL):** 100% автономная квалификация, но окончательное подписание договоров и утверждение скидок закреплено за человеком.
